# Recursos documentais da entrega

Os PDFs são entregues na central pública e no pacote de materiais:
https://alertacidadao-bi-jpczz.est-dio-like-0113.chatgpt.site/entrega

A versão GitHub contém o código. Os seguintes recursos documentais da implantação são mantidos separadamente:

- Dossie_AlertaCidadao_BI.pdf
- Dossie_AlertaCidadao_Modelo_Video.pdf (template com o campo de vídeo limpo)
- Pitch_AlertaCidadao.pdf
- Roteiro_Pitch_e_Gravacao.pdf
- Relatorio_Ensaio_Controlado.pdf
- Guia_Publicacao.pdf

A pasta public/docs do checkout de implantação mantém esses arquivos. Para reproduzir as páginas de materiais em outra instalação, coloque as cópias correspondentes nesta pasta antes de npm run build. O SHA-256 de Dossie_AlertaCidadao_Modelo_Video.pdf deve corresponder ao arquivo video-link-slot.json; o gerador recusa versões diferentes.

O MVP central (cadastros, cenários, notificações, leituras, painel e extração dos comprovantes em public/samples) é independente desses documentos.
